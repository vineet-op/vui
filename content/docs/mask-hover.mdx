## Overview

The **Mask Hover** component creates an interactive spotlight effect that follows your cursor. When you hover over the content, the mask expands to reveal hidden text with smooth animations.

## Features

- 🎯 Cursor-following spotlight effect
- ✨ Smooth mask size transitions
- 🎨 Fully customizable colors and text
- 📦 Self-contained (no external dependencies for mask)
- ⚡ Built with Framer Motion for smooth animations

## Props

| Prop                     | Type        | Default             | Description                                                     |
| ------------------------ | ----------- | ------------------- | --------------------------------------------------------------- |
| `className`              | `string`    | -                   | Additional CSS classes for the root container                   |
| `heroContent`            | `ReactNode` | Default hero text   | Content shown behind the mask                                   |
| `maskRevealContent`      | `ReactNode` | Default reveal text | Content revealed inside the spotlight                           |
| `backgroundColor`        | `string`    | `"bg-neutral-950"`  | Page background (Tailwind class or CSS color)                   |
| `maskBackgroundColor`    | `string`    | `"lightcoral"`      | Spotlight circle background color                               |
| `maskTextColor`          | `string`    | `"#171717"`         | Default text color inside the mask                              |
| `initialMaskSize`        | `number`    | `40`                | Mask circle size in px when not hovered                         |
| `hoverMaskSize`          | `number`    | `400`               | Mask circle size in px when hovered                             |
| `maskTransitionDuration` | `number`    | `0.3`               | Duration (seconds) of mask transitions                          |
| `maskTransitionEase`     | `string`    | `"backOut"`         | Easing function for mask animation                              |
| `maskSvg`                | `string`    | Circle SVG          | Custom SVG for mask shape (use `fill="white"` for visible area) |

The component uses:

1. **MousePointer hook** - Tracks cursor position in real-time
2. **CSS Mask** - Creates the spotlight effect using inline SVG data URL
3. **Framer Motion** - Animates mask position and size smoothly
4. **Hover state** - Expands the mask when hovering over the reveal content

The mask is self-contained with an inline SVG, so no external files are needed.
