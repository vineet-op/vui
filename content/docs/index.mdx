## Hey there! 👋

I'm **Vineet**, a frontend developer who loves building beautiful interfaces. VUI started as a personal collection of components I kept reusing across projects—and I thought, why not share them with everyone?

## Why I Built This

As developers, we spend too much time recreating the same UI patterns. I wanted to create a library where you can simply copy what you need and move on to building the actual product. No bloated dependencies, no complex setup—just clean, animated components that work.

## What You'll Find Here

VUI is a growing collection of components built with **Tailwind CSS**, **shadcn/ui**, and **Framer Motion**. Each component is:

- ✨ **Ready to use** - Copy, paste, done
- 🎨 **Beautifully animated** - Smooth interactions out of the box
- 🔧 **Easy to customize** - Tailwind makes styling a breeze
- 📱 **Fully responsive** - Works on all screen sizes
- 💪 **TypeScript** - Fully typed for better DX

## The Philosophy

Keep it simple. Keep it beautiful. Make it reusable.

I believe UI components should be easy to understand and modify. That's why every component here is self-contained and well-documented. No magic, no hidden complexity—just good code you can learn from and build upon.

## Open Source & Free

VUI is completely free and open source. Use it in your personal projects, commercial work, or anywhere else. If you find it helpful, consider starring the repo or sharing it with others.

## Let's Build Together

Have ideas for new components? Found a bug? Want to contribute? I'd love to hear from you. This is a community project, and your feedback makes it better.

Happy building! 🚀
