## Overview

The **Text Stagger** component creates a smooth letter-by-letter animation effect on hover. Each character animates with a staggered delay, creating a wave-like transition that reveals alternate text underneath.

## Props

| Prop           | Type     | Default                                        | Description                                   |
| -------------- | -------- | ---------------------------------------------- | --------------------------------------------- |
| `children`     | `string` | -                                              | The text to animate (required)                |
| `href`         | `string` | -                                              | Link URL (required)                           |
| `className`    | `string` | `"relative block overflow-hidden text-4xl..."` | Custom CSS classes for styling                |
| `duration`     | `number` | `0.25`                                         | Animation duration in seconds per letter      |
| `staggerDelay` | `number` | `0.025`                                        | Delay between each letter animation (seconds) |

### Timing Presets

```tsx
// Subtle (slow and smooth)
<TextStagger duration={0.4} staggerDelay={0.04}>Subtle</TextStagger>

// Snappy (fast and responsive)
<TextStagger duration={0.15} staggerDelay={0.01}>Snappy</TextStagger>

// Dramatic (very slow)
<TextStagger duration={0.6} staggerDelay={0.08}>Dramatic</TextStagger>
```
